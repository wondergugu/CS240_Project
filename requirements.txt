# Streamlit demo dependencies — installed ONLY into the isolated .venv-streamlit
# (see run_app.sh), never into the base env.
#
# Why isolated: streamlit==1.58.0 hard-requires anyio>=4, but the base env's
# jupyter-server 1.24 / jupyterlab 3.2.5 require anyio<4. The two cannot share one
# anyio version, so streamlit lives in its own venv with anyio>=4 while the base
# env keeps anyio 3.7.1 (jupyter stays working). The venv is created with
# --system-site-packages, so torch / transformers / sentence-transformers / numpy
# / pandas / pyarrow / protobuf are REUSED from the base env (not reinstalled);
# only streamlit + its pure-python web stack (anyio>=4, starlette, uvicorn, altair,
# ...) are added locally. All inference stays local / open-weight; no commercial API.
#
# Usage:  bash run_app.sh        (creates/repairs the venv, then launches the app)
